# TGCN 索引 · Telegram 中文搜索机器人

在地铁上搜一套猫咪贴纸，或跟同事共享屏幕找一个科技频道，都应该是件轻松的事。

- **先看搜索结果。** TGCN 拒绝博彩、资金盘等黑灰产广告。私聊里如果有关键词广告，只展示经过人工审核、与搜索词相关的推广，放在自然搜索结果之后，每条都标明「广告」。
- **18+ 模式默认关闭。** 日常搜索会过滤已标记的 **NSFW（成人）内容**。想查看这类结果，需要在私聊 `/settings` 或 Mini App 里主动打开 18+，并确认已满 18 岁。两个入口共用一个开关，随时可以关闭。

**[打开 Telegram 搜索机器人 @tgcn](https://t.me/tgcn)**，点「开始」，发一个你感兴趣的词。

## 可以搜什么？

TGCN 是面向中文用户的 Telegram 搜索引擎，也是可以直接在聊天里使用的电报群组和频道导航。频道、群组、机器人、帖子、贴纸、音乐和视频都可以按关键词搜索。简繁中文和常见的两岸用词也能相互匹配，例如用「软件下载」可以找到写着「軟體下載」的频道。

| 想找什么 | 在 @tgcn 里试试 |
| --- | --- |
| Telegram 中文频道 | 发送 `科技频道`，点开感兴趣的频道看简介，再决定要不要订阅。 |
| TG 群组与中文社群 | 发送 `英语学习群`，只看群组结果，按名称和简介挑一个适合交流的群。 |
| 实用机器人 | 搜 `群管理`，切到「机器人」，找能帮群主处理日常事务的 Bot。 |
| 频道帖子与原文 | 搜 `阳台种菜`，切到「帖子」，就能按主题翻找种植经验，点结果回到 Telegram 原文。 |
| 贴纸包与自定义表情 | 试试 `猫咪表情包` 或 `🐱`，预览喜欢的那一套，点包名在 Telegram 里打开。 |
| 音乐与音频 | 搜歌名或歌手，切到「音乐」。如果原帖提供了资料，结果里会列出格式、文件大小和来源频道。 |
| 视频与原消息 | 发送 `旅行视频`，用发布日期和视频时长一起筛选，点结果回到 Telegram 原视频。 |

## 三种好用的搜法

**私聊里精确找。** 想看最近发布的旅行长视频？搜 `旅行视频`，选「近 7 天」和「超过 5 分钟」，翻页会保留这两个条件。日期也可以选近 3 天或 30 天，时长还可以选超过 10 或 30 分钟。

**在群里边聊边搜。** 朋友问「有什么科技频道值得看？」时，直接在当前聊天的输入框里打 `@tgcn 科技频道`，用户名后留一个空格。等候选出现，点一条就发到群里。这就是 Telegram 内联搜索（inline search），省掉切回私聊、复制链接、再切回群的几步。

如果群主已启用群内搜索，还可以直接发 `/s 科技频道`。即使你在私聊打开了 18+，机器人发给全群的这份结果仍会过滤已标记的成人内容，也不展示关键词广告。

**用 Mini App 发现和收藏。** 私聊发送 `/app` 打开 Telegram 小程序，可以按类型浏览结果、看榜单，把想回访的频道或群组加入收藏。用同一个 Telegram 账号换台设备，也能接着看收藏和搜索历史。没有特定关键词时，发 `/random` 打开「随便看看」，从一批频道、群组和机器人里挑，点「换一批」继续逛。

## 让更多人搜到你的频道或群组

运营公开频道、群组或机器人？可以免费向 TGCN 提交收录。在 **@tgcn 私聊**发送 `/submit @your_channel`，把示例里的 `@your_channel` 换成你的公开用户名或 `t.me` 链接。一批最多提交 10 个，空格或换行分隔。发送 `/mysubmits` 可以查看审核进度和结果。
