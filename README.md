# TGCN 索引 · Telegram 中文搜索

想找一个学英语的群、一段旅行视频，或一套猫咪贴纸？把关键词发给 `@tgcn`，就能搜索已收录的公开频道、群组、机器人、帖子、贴纸、音乐和视频。

**[在 Telegram 打开 @tgcn](https://t.me/tgcn)**

## 第一次搜索

打开机器人，点「开始」，试着发送下面任意一个关键词。

| 发给机器人的文字 | 可以怎么找 |
| --- | --- |
| `英语学习群` | 只看相关群组，点名称查看群组资料。 |
| `旅行视频` | 选「近 7 天」和「超过 5 分钟」缩小范围，点结果回到 Telegram 原视频消息。 |
| `猫咪表情包` | 浏览相关贴纸包，点名称打开喜欢的那一套。 |

想随便逛逛，可以发 `/random` 看一批频道、群组和机器人的推荐；也可以发 `/app`，在 Telegram 里打开 Mini App 搜索。

## 在聊天里分享搜索结果

朋友在群里问「有没有科技频道？」时，在聊天输入框输入 `@tgcn 科技频道`，等候选结果出现，点选一条就能发到当前聊天。

## 提交自己的频道或群组

私聊 `@tgcn`，发送 `/submit`，再发公开频道或群组的用户名或链接。用 `/mysubmits` 可以查看收录进度。
